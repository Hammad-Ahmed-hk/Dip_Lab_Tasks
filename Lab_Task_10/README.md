Huffman Coding: A basic implementation of Huffman coding is performed to compress pixel values based on their frequencies.
DCT Compression: The image is compressed using the Discrete Cosine Transform (DCT) by processing the image in 8x8 blocks.
Metrics Calculation: Compression Ratio (CR), Mean Squared Error (MSE), and Peak Signal-to-Noise Ratio (PSNR) are computed to evaluate the quality of the compression.
Visualization: The original and compressed images are displayed side by side for comparison.
