 Morphological Image Processing using OpenCV

 Overview

This project demonstrates basic **morphological image processing operations** using 
**Python and OpenCV** in **Google Colab**. The tasks include noise removal, 
boundary extraction, hole filling, and shape detection.

 Requirements

 Google Colab
 Python 3
 OpenCV, NumPy, Matplotlib
 Image stored in Google Drive

## How to Run
1. Open Google Colab
2. Mount Google Drive
3. Update the image path:

/content/drive/MyDrive/your_image.jpg
4. Run all cells

Tasks Performed

Erosion
Dilation
Opening
Closing
Boundary Extraction
Hole Filling (Watershed)
Noise Removal
Shape Detection (Contours)

 Output
 Visual comparison of all morphological operations
 Detected object boundaries and shapes
 Cleaned image with reduced noise

 Kernel size can be adjusted for different results
 Works with binary or colored images
